# 模板硬性要求摘录（据 2025.10.20 版四个 docx 提取）

> 用途：生成脚本与人工校对时的唯一依据。原件见仓库同级目录 `../*.docx`。

## 一、文献综述模板

| 项 | 要求 |
|---|---|
| 页边距 | 上下 2.54 cm，左右 3.17 cm |
| 封面 | 院（系）名称 / 专业名称 / 学生姓名 / 指导教师 + 日期；专业为「机械设计制造及其自动化」 |
| 封面题目 | 与论文题目相关但**不能一致** |
| 正文题目 | 黑体三号不加粗，居中，段前 0.5 行，与封面题目一致 |
| 摘要 | 100–200 字；「摘要：」二字加粗；内容小四宋体不加粗，24 磅行距，无段前段后，首行缩进 2 字符 |
| 关键词 | 3–5 个；「关键词：」加粗，首行缩进 2 字符 |
| 一级标题 | 形如「1 发展背景」，左对齐、两端对齐，小四号**黑体不加粗**，段前段后 0.5 行，24 磅行距 |
| 正文 | 小四号宋体，24 磅行距，两端对齐，首行缩进 2 字符，段前段后 0 |
| 字数 | 标题起至「参考文献」四字前止 **≥3000 字**（封面与参考文献不计） |
| 章节 | 1 发展背景 / 2 国内外发展现状 / 3 发展趋势 / 4 结论 |
| 参考文献 | **≥12 篇**；期刊 ≥80%；含 **2 篇英文**；以近五年为主；专著 ≤5 篇 |
| 著录细节 | 期刊须有年卷期、页码；硕博论文须注明城市及年限；英文标题首字母大写；作者姓名顺序 |
| 标点 | 全部英文标点；数字、字母、符号用 Times New Roman |

## 二、开题报告模板

| 项 | 要求 |
|---|---|
| 标题 | 「黄河科技学院毕业设计开题报告表」黑体小二 |
| 表头 | 宋体五号居中，西文数字用 Times New Roman |
| 课题名称 | 一般不超过 20 个汉字 |
| 课题来源 | 教师拟订 / 学生建议 / 企业和社会征集 / 科研单位提供 |
| 课题类型 | 两段都要填：A 工程设计 / B 技术开发 / C 软件工程 / D 理论研究 / E 调研报告 + X 真实 / Y 模拟 / Z 虚拟 |
| 正文 | 宋体五号，20 磅行距 |
| 各部分标题 | 宋体 5 号加粗，20 磅间距 |
| 结构 | 一、调研资料的准备；二、设计的目的与要求；三、设计的思路与预期成果（1 设计思路 2 预期成果 3 图表的规范化）；四、任务完成的阶段内容及时间安排；五、完成设计（论文）所具备的条件因素 |
| 字数 | **≥2000 字** |
| 落款 | 指导教师签名：____  2026 年 1 月 5 日 |
| 其他 | 所有文档用 Office 2010 格式（.docx） |

## 三、任务书模板（后续使用）

- 正文宋体小四，24 磅行距，首行缩进 2 字符；一级标题宋体小四左对齐，段前 0.5 行
- 页面：左 3 cm，上、下、右 2.5 cm
- 论文 ≥8000 字；参考资料 ≥12 篇，近 5 年，标点用英文字符
- 时间：2025-11-15 至 2026-05-15；计划答辩 2026-05-16

## 四、课题申报表模板（后续使用）

- 标题黑体三号居中；表格内宋体 5 号，行距 20 磅
- 含：选题背景 / 主要设计内容 / 设计成果形式及功能、技术指标要求 / 现有进度及条件 / 时间安排
- 审批：专业（教研室）2025-11-05，院（系）2025-11-15

## 五、通用格式细节

- 图：宽 ≤15 cm；图题黑体小 5 号，英文图题 Times New Roman 小 5 号
- 表：三线表；小表 <7.5 cm，大表 12–15 cm
- 变量斜体，单位正体，量/单位用「/」隔开
- 行距换算：24 磅 = 480 twips；20 磅 = 400 twips
