# 毕设 · 室内粉墙升降平台结构设计及运动分析

黄河科技学院 2026 届本科毕业设计（机械设计制造及其自动化）——四项材料的可迭代工程仓库。

- 题目：室内粉墙升降平台结构设计及运动分析
- 毕业设计时间：2025-11-15 ～ 2026-05-15，计划答辩 2026-05-16
- 本仓库目的：把四份材料的**正文源稿（Markdown）**与**成稿（.docx）**分离管理，格式调整只改脚本、内容修改只改源稿，便于反复迭代而不破坏格式。

## 目录

```
docs/            材料源稿与要求摘录
 00_模板要求摘录.md    从四个模板 docx 中提取的硬性格式/字数要求
 01_文献综述.md        文献综述正文源稿
 02_开题报告.md        开题报告正文源稿
 03_参考文献.md        参考文献（已核对著录信息）
 04_任务书.md          任务书正文源稿
 05_课题申报表.md      课题申报表正文源稿
src/             生成与校验脚本
 build_review.js      生成 文献综述.docx
 build_proposal.js    生成 开题报告.docx（支持 ![图题](路径) 图片块）
 build_task.js        生成 任务书.docx
 build_declare.js     生成 课题申报表.docx
 build_all.js         一次生成全部
 lib.js               统一样式（字体/行距/缩进/页边距）
 check.js             字数与格式自检
assets/          插图源文件
 技术路线图.drawio    开题报告图 1 的 draw.io 源文件（可编辑）
 技术路线图.png       导出的插图（1800×1660，插入宽 12.2 cm）
out/             生成的 .docx（提交进仓库，便于直接下载）
PROGRESS.md      当前进度与下一步（每次继续工作先读这个）
```

## 使用

```bash
npm install
npm run build      # 生成全部 docx
npm run check      # 字数/篇数/格式自检
```

插图重导出（改完 `assets/技术路线图.drawio` 后）：

```bash
"C:/Tools/drawio/draw.io.exe" -x -f png --width 1800 --disable-gpu \
  -o assets/技术路线图.png assets/技术路线图.drawio
```

draw.io 32.7.4 便携版解压在 `C:/Tools/drawio/`，无安装、可整目录删除。

## 格式约束（速查）

- 文献综述：页边距上下 2.54 / 左右 3.17 cm；正文小四宋体 24 磅行距首行缩进 2 字符；正文 ≥3000 字；参考文献 ≥12 篇、期刊 ≥80%、2 篇英文。
- 开题报告：宋体五号 20 磅行距；≥2000 字；表格式。
- 数字、英文、符号一律 Times New Roman；标点用英文标点。

## 待填（占位符）

生成稿中所有 `【】` 为待填项：姓名、学号、班级、指导教师、课题类型。在 Word 里替换即可，也可改 `src/config.js` 后重新生成。
